
# Desktop-приложение «Калькулятор» на основе WPF и C#

Этот проект представляет собой desktop-приложение калькулятора с поддержкой стандартного и инженерного режимов вычислений, вынесением бизнес-логики в сервисы и ведением истории операций. Проект выполнен на C# (WPF) с соблюдением принципов слабой связанности компонентов.

## Установка

1. Клонируйте репозиторий:
   git clone [https://github.com/SonyDeWild/KarpovaSofiaYurevna_LR1](https://github.com/SonyDeWild/KarpovaSofiaYurevna_LR1)
   cd KarpovaSofiaYurevna_LR1


2. Откройте файл решения в Visual Studio:

start KALKULATOR.sln

3. Соберите проект в Visual Studio:
Скомпилируйте решение с помощью `Ctrl + Shift + B` или запустите приложение нажатием `F5`.

## Использование

### Запуск калькулятора

Для запуска приложения выполните сборку в Visual Studio или запустите исполняемый файл из папки сборки:

./bin/Debug/KALKULATOR.exe


### Пример работы программы

Чтобы выполнить вычисление, введите выражение на клавиатуре или с помощью кнопок интерфейса:

**Ожидаемый вывод:**

Ввод: "2+2*2"

Вердикт: 6

## Структура проекта

* `Views/`: Графический интерфейс (окна MainWindow.xaml и EngineerCalculator.xaml).
* `Services/`: Сервисы вычислений (CalculatorService.cs) и работы с логами (HistoryLog.cs).
* `calculator_log.txt`: Файл с сохранённой историей операций.

## Данные

Используется локальный текстовый файл `calculator_log.txt`, содержащий истории всех вычисленных выражений с меткой времени.
